1ホイールのモデルを作る

1Model the wheel

ホイールを作るのは必須ではありません

カーパックでホイールを用意しなければ、KurumaMod 標準のホイール（TE37）が自動で付きます。このガイドは、自分でホイールをデザインしたい人のためのものです。

Making a wheel is optional

If your car pack has no wheel of its own, KurumaMod's standard wheel (the TE37) is fitted automatically. This guide is for those who want to design their own wheel.

ホイールを Blender で作り、OBJ に書き出すまでです。ホイールは車体とは別のファイルで作ります。

This chapter takes a wheel from Blender to an exported OBJ. Wheels are built in a separate file from the body.

最小のホイールを作る

Make a minimal wheel

  1. Blender新しいファイルで、ゲージを置く。Scripting タブで modeling_tools/blender_wheel_gauge.py を実行する。寸法は同梱の TE37 に合わせてあり、リムの外形（半径 0.352m・幅 0.32m）・デザイン面の限界・嵌まるタイヤの断面（外径 0.45m）・車軸の線・地面・表を示す矢印が置かれる。リムは外形の円柱の中へ収める
  2. Blender円柱に収まるように、リムだけを作る。両端のフランジを円柱の端の面に合わせる。幅はどのホイールも同じ 0.32m（規格）なので、細い・太いを作り分けない（太さは換装画面のスライダーで変える）。原点は車軸の中心、つまりリムの幅の真ん中に置く。円柱から作るなら、先に R Y 9 0 で回して軸を左右（X）へ向ける
  3. Blenderホイールの表（デザイン面）を +X へ向ける。ゲージの矢印の側。作るのは左側用の 1 つだけ
  4. Blenderタイヤは作らない。タイヤは描くときに自動で嵌まる（換装画面で選んだタイヤ、選んでいなければ KurumaMod 標準のタイヤ）
  5. Blenderゲージを除いてホイールだけを選び、OBJ に書き出す。「Selected Only」を入れ、「Triangulated Mesh」は入れない（設定の全体は車の 5 章と同じ）
  6. ファイル書き出したファイルとテクスチャを置く。assets/mypack/models/entity/my_wheel.obj（.mtl も一緒に）と assets/mypack/textures/entity/my_wheel.png

これで、ホイールのモデルができました。換装画面で選べるようにするのは 2 章、自分の車に最初から履かせるのは下の「自分の車に最初から履かせたい」です。

  1. BlenderIn a new file, place the gauge. Run modeling_tools/blender_wheel_gauge.py from the Scripting tab. Sized after the bundled TE37, it places the rim envelope (0.352 m radius, 0.32 m wide), the limit for the design face, the section of the tyre that fits on it (0.45 m outer radius), the axle line, the ground and an arrow marking the outer face. Keep the rim inside the envelope
  2. BlenderModel only the rim, inside the cylinder, with both flanges on the cylinder's end faces. Every wheel has the same 0.32 m width (a fixed standard), so do not build narrow or wide rims; width is set with the slider in the parts screen. Put the origin at the axle centre, which is the middle of the rim's width. If you start from a cylinder, first rotate it with R Y 9 0 so its axis runs left–right (X)
  3. BlenderPoint the face of the wheel (the design side) towards +X, the side the gauge arrow points to. Build the left-hand wheel only
  4. BlenderDo not model a tyre. One is fitted automatically when drawn: the tyre picked in the parts screen, or KurumaMod's standard tyre if none is picked
  5. BlenderSelect only the wheel (not the gauge) and export it as OBJ. Tick "Selected Only" and leave "Triangulated Mesh" off (the full settings are the same as chapter 5 of the Car guide)
  6. FilePut the exported file and the texture in your pack: assets/mypack/models/entity/my_wheel.obj (with its .mtl) and assets/mypack/textures/entity/my_wheel.png

The wheel model is done. To make it selectable in the parts screen, go to chapter 2; to fit it to your own car from the start, see "Fit it to my own car" below.

必要なときだけ

Only when you need it

自分の車に最初から履かせたい

ホイールを部品にして（2 章）、車の諸元の JSON data/mypack/cars/<車>.json の default_parts で指します。換装画面ではこれが「純正」になります:

{
  "values": { ... },
  "default_parts": { "wheel": "mypack:my_wheel" }
}
  • 書かなければ、KurumaMod の TE37 が純正になる
  • ほかの車には履かせたくないなら、部品の data/mypack/car_parts/my_wheel.json に "cars": ["mypack:<車>"] を書く
  • 車の見た目の JSON（vehicles/）にはホイールのモデルを書かない。ホイールの項目は何も書かない（タイヤの位置は諸元のトレッド・ホイールベースが決める）
Fit it to my own car

Make the wheel a part (chapter 2) and point to it from default_parts in the car's spec JSON data/mypack/cars/<car>.json. It becomes "Stock" in the parts screen:

{
  "values": { ... },
  "default_parts": { "wheel": "mypack:my_wheel" }
}
  • Left out, KurumaMod's TE37 is the stock wheel
  • To keep it off other cars, add "cars": ["mypack:<car>"] to the part file data/mypack/car_parts/my_wheel.json
  • Do not name the wheel model in the car's looks JSON (vehicles/). No wheel entries go there at all (the spec's track and wheelbase decide where the wheels sit)
ゲージと違う大きさで作りたい

大きさは自由です。作った半径（m）を、ホイールの見た目のファイル assets/mypack/car_parts/my_wheel.json（2 章）の wheel の中に "designRadius" で書きます。ゲームは、この値と車のタイヤ半径の比で拡大して描きます。書かなければゲージの 0.45 とみなします。

"wheel": { "model": "mypack:models/entity/my_wheel.obj",
           "texture": "mypack:textures/entity/my_wheel.png",
           "designRadius": 0.30 }

ゲーム内の調整画面でタイヤ半径を変えると、見た目もそのまま追従します。タイヤは接地したまま、車体だけが上がります（リフトアップ）。

Build it at a different size from the gauge

Any size is fine. Write the radius you built at (in m) as "designRadius" inside wheel in the wheel's looks file assets/mypack/car_parts/my_wheel.json (chapter 2). The game scales the mesh by the ratio between this value and the car's tyre radius. Left out, it is taken as the gauge's 0.45.

"wheel": { "model": "mypack:models/entity/my_wheel.obj",
           "texture": "mypack:textures/entity/my_wheel.png",
           "designRadius": 0.30 }

Change the tyre radius in the in-game tuning screen and the model follows: the tyres stay on the ground and the body rises (a lift-up).

ホイールごと KurumaMod のものを使いたい

何も書かなければ、KurumaMod の TE37（部品の id は kurumamod:te37）が純正になります。

Use KurumaMod's whole wheel

Write nothing: KurumaMod's TE37 (part id kurumamod:te37) is the stock wheel.

仕組みを知りたい（なぜリムだけでよいのか）

リムもタイヤも、ビードからビードまでの幅を同じ 0.32m（ゲージの円柱）で作る約束になっています。だから、どのリムにどのタイヤを嵌めても幅が合います。

  • タイヤは、内径がリムのいちばん外側の半径の 95% へ、外径が車のタイヤ半径へ来るように伸び縮みして描かれる。リムを大きく作るほどサイドウォールが薄くなる（インチアップ）
  • 太さのスライダーは、リムとタイヤに一緒に効く。だからメッシュで太さを作り分ける必要がない
  • シェーダーパックの影は、タイヤだけが落とす。地面にスポークの模様が出ない

以前は、ホイールにタイヤも一緒に作り、名前を Tire にする作り方でした。この作り方のホイールも読めますが、tire で始まる名前のオブジェクトは描かれず、選んだタイヤ（選んでいなければ KurumaMod 標準のタイヤ）が嵌まります。付属のタイヤの内径は、タイヤを嵌める位置としてだけ使われます。

How it works (why the rim alone is enough)

Rims and tyres are both built to the same 0.32 m bead-to-bead width (the gauge cylinder). So any tyre fits any rim.

  • The tyre is stretched so its inner edge sits at 95% of the rim's outermost radius and its outer edge at the car's tyre radius. A bigger rim gives thinner sidewalls (plus-sizing)
  • The Width slider acts on the rim and tyre together, so there is no need to build different widths into the mesh
  • With shader packs, only the tyre casts a shadow, so no spoke pattern appears on the ground

Wheels used to be built with their own tyre as a separate object named Tire. Such wheels still load, but objects whose name starts with tire are not drawn; the picked tyre (or KurumaMod's standard tyre) is fitted instead. The built-in tyre's inner edge is only used to place the fitted tyre.

ゲームの中で、キャンバー・太さ・半径を合わせたい

Ctrl+G の「ホイールの JSON」で、乗ったまま動かせます。手順は2 章の「ゲームの中で調整する」にあります。タイヤの位置（幅・前後）は諸元のトレッド・ホイールベースで決まるので、調整画面（G）で動かします。

Set camber, width and radii in game

The "Wheel JSON" tab of Ctrl+G moves them while you sit in the car. The steps are in "Adjust it in game" in chapter 2. Wheel position (width, front to back) comes from the spec's track and wheelbase, so move those in the tuning screen (G).

うまくいかないとき
  • タイヤが大きすぎる・小さすぎる … ゲージと違う大きさで作ったのに、wheel の中に designRadius を書いていない（または作った半径になっていない）
  • 回るとぶれる・地面に埋まる・浮く … 原点が車軸の中心にない。タイヤの底に置いていないか見る
  • タイヤが横倒しで転がる … 回転軸が左右（X）を向いていない。R Y 9 0 で回す
  • 右側のタイヤの表が内側を向く … 表が +X を向いていない。左側用として作り直す（右側は MOD が鏡像にして描く）
  • 1 か所にタイヤが 2 本描かれる … 左右 2 つ作っている。左側用の 1 つだけにする
  • タイヤがリムに食い込む・リムとの間に隙間がある … リムの幅がゲージの円柱と合っていない。フランジを円柱の両端の面に合わせる
  • タイヤが二重に描かれる … リムと一緒にタイヤも作っている。タイヤを消してリムだけにする
  • 全体が白い … .mtl を置いていないか、マテリアルが無い。形が正しければ問題ない（色の付け方は車の 4 章）
When it doesn't work
  • Wheels too big or too small — you built at a size other than the gauge but did not write designRadius inside wheel (or it is not the radius you built at)
  • Wobbles as it spins, sinks into the ground, or floats — the origin is not at the axle centre. Check it is not at the bottom of the tyre
  • Rolls on its side — the spin axis does not run left–right (X). Rotate with R Y 9 0
  • The right-hand wheels face inward — the face is not towards +X. Rebuild it as the left-hand wheel (the mod mirrors it for the right)
  • Two tyres drawn in one place — you modelled both sides. Keep only the left-hand one
  • The tyre cuts into the rim, or there is a gap between them — the rim's width does not match the gauge cylinder. Put the flanges on the cylinder's end faces
  • Two tyres drawn on one wheel — you modelled a tyre along with the rim. Delete it and keep only the rim
  • Everything is white — no .mtl, or no material. Harmless if the shape is right (colouring is in chapter 4 of the Car guide)

2ホイールを部品にする

2Make a wheel a part

作ったホイールを、ゲームの換装画面で選べるようにします。見た目だけの部品で、走りは変わりません。

Make your wheel selectable in the in-game parts screen. It changes the looks only; driving stays the same.

最小のホイール部品を作る

Make a minimal wheel part

  1. Blenderホイールのモデルを作って置く。作り方は 1 章。ここでは assets/mypack/models/entity/my_wheel.obj と assets/mypack/textures/entity/my_wheel.png に置いたとする
  2. ファイル部品のファイルを置く。data/mypack/car_parts/my_wheel.json（ファイル名が部品名）: 
    { "slot": "wheel" }
  3. ファイル見た目のファイルを置く。assets/mypack/car_parts/my_wheel.json（部品と同じファイル名）。ゲージどおりに作ったなら、大きさは書かなくてよい: 
    {
  "wheel": {
    "model": "mypack:models/entity/my_wheel.obj",
    "texture": "mypack:textures/entity/my_wheel.png"
  }
}
  4. lang表示名を lang に書く。"part.mypack.my_wheel": "マイホイール"

これで、ゲームの G →「パーツ」→「ホイール」のタブに並びます。

  1. BlenderBuild the wheel model and put it in your pack. See chapter 1. Here it is at assets/mypack/models/entity/my_wheel.obj and assets/mypack/textures/entity/my_wheel.png
  2. FileAdd the part file data/mypack/car_parts/my_wheel.json (the file name is the part name): 
    { "slot": "wheel" }
  3. FileAdd the looks file assets/mypack/car_parts/my_wheel.json (same file name as the part). If you built to the gauge, there is no size to write: 
    {
  "wheel": {
    "model": "mypack:models/entity/my_wheel.obj",
    "texture": "mypack:textures/entity/my_wheel.png"
  }
}
  4. langAdd the display name to lang. "part.mypack.my_wheel": "My Wheels"

It now appears under G → "Parts" → the "Wheels" tab.

ゲームの中で調整する

Adjust it in game

キャンバー・太さの最初の値や、タイヤの嵌まり具合は、ゲームの中で見ながら決められます。JSON を書き換えて読み直すのを繰り返す必要はありません。

The starting camber and width, and how the tyre sits on the rim, can be set while watching in game. No need to keep editing the JSON and reloading.

ゲージどおりに作ったなら、基本的に変更は要りません

この調整は、ゲージ（blender_wheel_gauge.py）どおりの大きさで作られなかったメッシュのためのものです。ゲージに収めて作ったホイールなら、スケールもビード半径もそのままで標準のタイヤがぴったり嵌まります。キャンバーと太さは好みの最初の値を決めたいときだけ動かします。

Built to the gauge? You normally change nothing here

This is for meshes that were not built at the gauge's size (blender_wheel_gauge.py). A wheel kept inside the gauge takes the standard tyre exactly with the scale and bead radius left as they are. Move camber and width only if you want different starting values.

  1. ゲーム車を出して乗り、自分のホイールを履かせる。G →「パーツ」→「ホイール」で選ぶ（純正にしてあれば、そのままでよい）
  2. ゲームCtrl+G を押し、上の「ホイールの JSON」のタブを開く。タブに貼り先のファイル名（my_wheel.json）が出る
  3. ゲームスライダーか −／＋ で動かし、その場で見る。Shift を押しながらだと 10 刻み。三人称（F5）ならドラッグで車のまわりを回して見られる
    • キャンバー・太さ … 換装画面のスライダーの最初の値になる
    • スケール … ホイールの大きさ（designRadius）。ゲージどおりに作ったなら 0.45 のまま
    • ビード半径 … タイヤの内側を置く半径。タイヤがリムに食い込む・浮くときだけ動かす。書いていなければ「測定」と出る
  4. ゲーム「JSON をコピー」を押す。モデルとテクスチャも入った "wheel" のブロックがコピーされる
  5. ファイルassets/mypack/car_parts/my_wheel.json の "wheel" のブロックと置き換えて貼る。F3+T で読み直して確かめる
  1. GameSpawn a car, get in and fit your wheel. Pick it under G → "Parts" → "Wheels" (skip this if it is already the stock wheel)
  2. GamePress Ctrl+G and open the "Wheel JSON" tab at the top. The tab shows the file to paste into (my_wheel.json)
  3. GameMove the sliders or −/+ and watch the result. Hold Shift for steps of 10. In third person (F5) you can drag to look around the car
    • Camber, Width — become the starting values of the parts-screen sliders
    • Scale — the wheel's size (designRadius). Leave it at 0.45 if you built to the gauge
    • Bead radius — where the tyre's inner edge sits. Move it only if the tyre cuts into or floats off the rim. Shows "measured" when not written
  4. GamePress "Copy JSON". It copies the "wheel" block, model and texture included
  5. FileReplace the "wheel" block in assets/mypack/car_parts/my_wheel.json with it. Press F3+T to reload and check
  • 動かした値は自分の画面だけ・ゲームを閉じるまで。ほかの人や保存データには影響しない
  • 各行の「R」で JSON の値に戻る（JSON に書いていない項目は、書いていない状態に戻る）
  • 灰色の行は、換装画面で変えた値や部品の指定が勝っていて、動かしても見えない。換装画面で「R」を押して戻すと動くようになる
  • Changes apply on your screen only, until you close the game. Other players and saves are not affected
  • "R" on a row goes back to the JSON's value (an entry the JSON does not write goes back to unwritten)
  • Grey rows are overridden by values changed in the parts screen or by the part itself, so moving them shows nothing. Press "R" in the parts screen to clear the override

必要なときだけ

Only when you need it

オフセット・キャンバー・太さの最初の値を決めたい

見た目のファイル assets/mypack/car_parts/my_wheel.json の wheel に書きます。換装画面のスライダーの最初の位置になり、プレイヤーが「R」を押すとここへ戻ります。

{
  "wheel": {
    "model": "mypack:models/entity/my_wheel.obj",
    "texture": "mypack:textures/entity/my_wheel.png",
    "offset": [0.02, 0.0, 0.0],
    "scale": [1.3, 1.0, 1.0],
    "camber": -4.0
  }
}
  • offset … X だけ使う。外へ出す量 [m]（−0.05〜0.10）
  • scale … X だけ使う。太さの倍率（0.5〜2.5）。Y・Z は 1.0 のままにする（変えると接地が崩れる）
  • camber … キャンバー角 [度]。負で上が内側（−30〜10）
  • 範囲の外に書いた値は、端に丸めて読む
  • 書かなかった項目は、その車のホイールの値になる
Set the starting offset, camber and width

Write them under wheel in the looks file assets/mypack/car_parts/my_wheel.json. They become where the parts-screen sliders start, and "R" returns to them.

{
  "wheel": {
    "model": "mypack:models/entity/my_wheel.obj",
    "texture": "mypack:textures/entity/my_wheel.png",
    "offset": [0.02, 0.0, 0.0],
    "scale": [1.3, 1.0, 1.0],
    "camber": -4.0
  }
}
  • offset — only X is used: how far out to push the wheel [m] (−0.05 to 0.10)
  • scale — only X is used: width multiplier (0.5 to 2.5). Leave Y and Z at 1.0 (changing them breaks ground contact)
  • camber — camber in degrees. Negative leans the top inward (−30 to 10)
  • Values outside the range are clamped to the nearest end
  • Anything you leave out takes the car's own wheel value
メッシュを作らず、角度や太さだけ変えた部品にしたい

model と texture を書かなければ、その車のホイールのまま、書いた値だけが変わります。見本パックの deep_dish がこの形です。assets/mypack/car_parts/deep_dish.json:

{
  "wheel": {
    "scale": [1.6, 1.0, 1.0],
    "camber": -12.0
  }
}

ただし、スライダーで作れる状態に名前を付けるだけになるので、ふつうはメッシュを持つホイールを作ります。

A part with no mesh, only a different angle or width

Leave out model and texture; the car's own wheel is kept and only the values you write change. The example pack's deep_dish works this way. assets/mypack/car_parts/deep_dish.json:

{
  "wheel": {
    "scale": [1.6, 1.0, 1.0],
    "camber": -12.0
  }
}

This only names something players can already make with the sliders, so usually you would build a wheel with its own mesh.

決まった車種にだけ付けたい

うまくいかないとき
  • 換装画面に並ばない … data/ 側のファイルが無いか、slot が書かれていない（ログに出る）。cars で絞っているなら、乗っている車種が入っているか見る
  • 並ぶが、見た目が変わらない … assets/ 側のファイル名が data/ 側と違う。または "wheel": { ... } の中のキーの綴りが違う
  • 名前が my_wheel のまま出る … lang のキーが part.<パック>.<部品名> になっていない
  • 大きすぎる・小さすぎる … ゲージと違う大きさで作ったのに、designRadius を書いていない（または作った半径になっていない）
  • 付けても走りが変わらない … ホイールは見た目だけの部品。グリップを変えたいならタイヤ（タイヤの 2 章）
When it doesn't work
  • Not in the parts screen — the data/ file is missing, or has no slot (the log says so). If you use cars, check the car you are in is listed
  • Listed, but the looks do not change — the assets/ file name differs from the data/ one, or a key inside "wheel": { ... } is misspelt
  • The name shows as my_wheel — the lang key is not part.<pack>.<part>
  • Too big or too small — you built at a size other than the gauge but did not write designRadius (or it is not the radius you built at)
  • Driving does not change — wheels are looks only. To change grip, make a tyre (chapter 2 of the Tyre guide)
