1見本を手に入れる

1Get the example

自分のカーパックは、見本の ExampleCarPack を土台にして作ります。中身をコピーして、名前を自分のパックのものに置き換えます。車もホイールもパーツも、このフォルダの中に足していきます。

Your own car pack starts from the ExampleCarPack. Copy its contents and swap its name for your pack's. Cars, wheels and parts all go into this folder.

ここでは、パックの名前を mypack とします。

Here the pack is called mypack.

  1. ファイルExampleCarPack の jar をダウンロードする。CurseForge ↗ か Modrinth ↗ から
  2. ファイル拡張子を .jar から .zip に変える。
  3. ファイルzip を mypack/ フォルダに解凍する。
  1. FileDownload the ExampleCarPack jar. From CurseForge ↗ or Modrinth ↗
  2. FileChange its extension from .jar to .zip.
  3. FileExtract the zip into a mypack/ folder.

2名前を置き換える

2Replace the name

kurumamod_example_carpack を、すべて mypack に置き換える。使える文字は a-z・0-9・_ だけ

  • フォルダ名 2 つ（assets/ の下と data/ の下）
  • いちばん上のロゴ画像 kurumamod_example_carpack.png のファイル名
  • META-INF/mods.toml と META-INF/neoforge.mods.toml の中身。modId・logoFile・[[dependencies.…]]（2 か所）を置き換え、version・displayName・description も自分のものにする。2 つのファイルとも同じように直す 
    [[mods]]
modId = "mypack"                     # 置き換える
version = "1.0.0"                    # 自分のパックの版
displayName = "My Car Pack"          # MOD 一覧に出る名前
logoFile = "mypack.png"              # 置き換える
description = '''...'''              # MOD 一覧に出る説明文

[[dependencies.mypack]]              # 置き換える（2 か所とも）
  • JSON の中のパス

Replace every kurumamod_example_carpack with mypack. Use only a-z, 0-9 and _

  • Two folder names (under assets/ and under data/)
  • The file name of the logo image kurumamod_example_carpack.png at the top
  • The contents of META-INF/mods.toml and META-INF/neoforge.mods.toml. Replace it in modId, logoFile and both [[dependencies.…]], and make version, displayName and description your own. Edit both files the same way 
    [[mods]]
modId = "mypack"                     # replace
version = "1.0.0"                    # your pack's version
displayName = "My Car Pack"          # name in the mod list
logoFile = "mypack.png"              # replace
description = '''...'''              # description in the mod list

[[dependencies.mypack]]              # replace (both of them)
  • The paths inside the JSON

必要なときだけ

Only when you need it

置き換える場所を 1 つずつ確かめたい

kurumamod_example_carpack を、自分のパックの名前（例 mypack）に全部置き換えます。

  1. META-INF/mods.toml と META-INF/neoforge.mods.toml の modId を変える。displayName・description・version も自分のものにする
  2. assets/kurumamod_example_carpack/ と data/kurumamod_example_carpack/ のフォルダ名を modId と同じにする
  3. JSON の中の kurumamod_example_carpack:（モデルのパス）と、lang のキー（car.kurumamod_example_carpack.sample など）も置き換える
  4. MOD 一覧の画像を変えるなら、png を差し替えて logoFile の名前を合わせる
  • modId に使えるのは a-z 0-9 _ だけ（先頭は英字）。- や . を入れると、ゲームが起動時に Invalid modId で落ちる
  • フォルダ名（名前空間）は modId と同じにする。違っても動くが、ほかのパックとぶつかったときにどちらが読まれるか分からない
  • 車種のファイル名と名前の決まりは車の 6 章
Check each place to replace, one by one

Replace every kurumamod_example_carpack with your pack's name (e.g. mypack).

  1. Change modId in META-INF/mods.toml and META-INF/neoforge.mods.toml. Make displayName, description and version your own too
  2. Rename the folders assets/kurumamod_example_carpack/ and data/kurumamod_example_carpack/ to match modId
  3. Replace kurumamod_example_carpack: inside the JSON (model paths) and in the lang keys (car.kurumamod_example_carpack.sample and so on)
  4. For your own mod-list image, swap the png and update logoFile to its name
  • modId may only use a-z 0-9 _ (starting with a letter). A - or . crashes the game at start-up with Invalid modId
  • Make the folder name (the namespace) the same as modId. It works otherwise, but if two packs collide you cannot tell which one wins
  • Car file names and naming rules are in chapter 6 of the Car guide

mypack/ を開いたすぐ下に META-INF/ と pack.mcmeta があれば OK です。

It is right if META-INF/ and pack.mcmeta sit directly inside mypack/.

That is your car pack folder. Packing it into a jar is in chapter 1 of Shipping.

必要なときだけ

Only when you need it

見本の中の要らないファイルを消したい

CURSEFORGE.md・MODRINTH.md・modeling_tools/・sound_tools/ は、作るための説明書きと道具です。消しても、入れたままでも構いません。

見本は自由に使えます。コピーして自分のパックの土台にしてよく、表示も許諾も要りません。

Remove the files you don't need from the example

CURSEFORGE.md, MODRINTH.md, modeling_tools/ and sound_tools/ are documentation and tools for making packs. Delete them or keep them.

The example is free to use. Copy it as the base of your own pack; no credit or permission needed.
